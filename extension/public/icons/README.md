# MeetMind Icon Placeholder

Icon files should be placed here:
- icon16.png (16x16)
- icon32.png (32x32)
- icon48.png (48x48)
- icon128.png (128x128)

For now, you can use any PNG images with the MeetMind logo or brain emoji.

To generate icons:
1. Create a 128x128 PNG with your logo/design
2. Use an online tool to resize to other dimensions
3. Or use ImageMagick: `convert icon128.png -resize 48x48 icon48.png`

Temporary solution: Use emoji or solid color placeholders.
